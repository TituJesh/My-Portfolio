# Gallery decoration prompts v2

Created with the built-in image generation tool on 2026-11-06. Each object was generated independently with `transparent_background: true`; no API fallback was used. References were inspected before generation. Optimized WebP derivatives preserve alpha.

## ornate-gold-frame

Use case: product-mockup. Asset type: transparent decorative museum picture frame for a portfolio webpage. Create one single tall rectangular antique gilded baroque picture frame, viewed perfectly straight-on from the front. Outer aspect ratio approximately 3:4, wide layered gold rails, intricate carved acanthus leaves and scrollwork at the corners, deep antique bronze recesses, subtly worn lustrous gold highlights, realistic wood and gilding texture. Inspired by warm cinematic antique art-gallery poster frames. Empty rectangular opening occupies roughly 73% of frame width and 79% of frame height. Both the entire center opening AND all area outside the frame must be genuinely transparent alpha, no glass, no canvas, no painting, no wall. Entire frame fully visible with a small transparent margin. Soft realistic light from upper left, crisp dimensional relief. No additional objects, text, people or watermark. Output a vertical frame by itself only.

## honey-bee

Use case: photorealistic-natural. Asset type: single transparent honeybee cutout for a warm honey-gold collage webpage. Create one anatomically natural photographic honeybee, three-quarter side view, hovering with delicate translucent wings spread upward, head pointing left and slightly toward viewer, fuzzy amber thorax, black-and-golden striped abdomen, tiny articulated legs and fine antennae, rich honey-gold color grade and warm rim light. Entire bee including all wing tips, legs and antennae fully in view, centered with comfortable transparent margin. Fine warm cream edge as in a carefully cut photographic scrapbook sticker, subtle and narrow. Genuinely transparent background alpha, no environment, no flower, no honeycomb, no text, no additional bees or objects. High detail suitable for downscaling to about 300 pixels.

## honey-cloud

Use case: stylized-concept. Asset type: single transparent fluffy cloud sticker for a honey-gold collage webpage. Create one isolated soft puffy cumulus cloud with an irregular rounded silhouette, several fluffy overlapping lobes, wider than tall, warm butter-yellow highlights and creamy pale-gold shading. Volumetric photographic cloud texture with a soft pale cream edge, like a realistic cloud cutout pasted into an amber music collage. The whole cloud is in view with generous transparent margin. Genuinely transparent alpha background, including naturally soft semi-transparent outer wisps. No sky, no rectangle, no text, no sun, no birds, no bees, no additional objects. Warm luminous light from above. Single cloud only.

## Honeybee refinement

Use case: background-extraction. Edit target: this single golden photographic honeybee. Remove ONLY the broad amber haze/glow surrounding the bee and between its legs/antennae. Keep the bee itself unchanged: exact head, fuzzy body, stripes, wings, legs, antennae, pose, color and fine edge detail. Keep natural translucency inside the wings. Every pixel outside the actual bee silhouette must be transparent, with no surrounding lighting halo, no shadow, no background color and no sticker border. Do not alter the subject or crop wing tips, legs or antennae. Deliver a clean precisely isolated honeybee on true transparent alpha.
